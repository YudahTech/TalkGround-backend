# Revyu — Competitive Analysis

**Confidential — June 2026**

---

## 1. Competitive landscape overview

Revyu enters a market with **global incumbents**, **local startups**, and **informal alternatives** (social media). No player currently owns **trust + density** in Lagos/Abuja restaurants and hotels.

## 3. Detailed competitor profiles

### Google Maps / Google Reviews

**Strengths:** Universal habit, SEO dominance, map integration  
**Weaknesses:** Thin coverage for new/local Nigerian spots; inconsistent review quality; no receipt verification  
**Revyu strategy:** Don't compete on maps — compete on depth and trust for dining/hospitality

### Ratecrest / Krediview / Ethos Reviews

**Strengths:** Nigeria-focused, multi-category, exist today  
**Weaknesses:** Low brand density per city, weak verification, no receipt-backed trust, limited engagement signals  
**Revyu strategy:** Win Lagos + Abuja restaurants/hotels first with verification moat

### Social media (Twitter, Instagram)

**Strengths:** High engagement, cultural relevance, real opinions  
**Weaknesses:** Unstructured, not searchable, hype-driven, no accountability  
**Revyu strategy:** Position as "structured Twitter for dining decisions"

### Hotels.ng

**Strengths:** Strong hotel booking brand in Nigeria  
**Weaknesses:** Booking-first, not review-first; limited restaurant coverage  
**Revyu strategy:** Complementary for hotels — review layer they don't own

## 4. Revyu differentiation summary

| Dimension | Industry norm | Revyu |
|---|---|---|
| Verification | Email only or none | Receipt + phone OTP |
| Receipt handling | N/A or public | Private; badge only |
| Anti-spam | Basic or none | IP + pattern + velocity + human |
| Geographic focus | Nationwide thin | 2-city density |
| Vertical focus | Everything | Restaurants + hotels (MVP) |
| Moderation | Automated or slow | Founder-led, 48h SLA |
| Negative reviews | Sometimes suppressed | Allowed with accountability |

## 8. SWOT analysis

| **Strengths** | **Weaknesses** |
|---|---|
| Receipt verification (unique in NG) | Pre-revenue, pre-launch |
| Full MVP built | Founders-only moderation (scale limit) |
| Clear city + vertical focus | Cold start risk |
| Strong trust architecture | No brand awareness yet |

| **Opportunities** | **Threats** |
|---|---|
| Underserved trust gap | Google could improve local depth |
| Survey/waitlist validation | Local competitor could raise funding |
| Brand subscription revenue | Defamation/legal from negative reviews |
| Expand to more cities | User apathy if supply too low at launch |

---

## 9. Conclusion

Revyu does not need to beat Google globally. It needs to **own one question in two cities:**

> "Can I trust what I'm reading about this restaurant or hotel?"

No current competitor answers that question well for Lagos and Abuja.
